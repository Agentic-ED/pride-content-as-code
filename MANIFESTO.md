# The Pride Manifesto

_From the AgenticED design handoff. Members change this manifesto with a pull request._

## Why this Guild exists

Keep learning content evergreen by treating it as code: versioned source that agents and
applications turn into the learner's interface at the moment of use.

## Who we are

Docs-as-code writers, learning engineers, developer educators and generative UI builders.

## What we value

- **Structured source** over finished pages. We keep facts, objectives and examples as
  plain, versioned source. Everything a learner sees is built from it.
- **Generated at the moment of use** over static learning assets. The learner's interface
  is generated when they need it, for their task, from the current source. It is never out
  of date.
- **Agents and applications** over documents to read. Content as code is agentified and
  applicationified: it runs as agents that coach and applications that respond.
- **Humans at the helm** over unattended generation. The Lion reviews and proposes. A human
  Guild lead decides what merges.

Pages, courses and documents still have their place. We would rather keep one living source
and let agents and applications meet each learner with what is true today.

## What we build

- Skills that turn structured learning source (facts, objectives, examples) into the
  interface a learner needs: explanations, practice, job aids, checks.
- Skills that keep source current: detect drift against product docs and releases, and
  propose updates as pull requests.
- Agents that coach learners from the current source, and applications that respond to
  the learner's task.
- Shared schemas and conventions for learning content kept in version control.

AgenticED's shared principles follow the ADGIE framework: https://adgie.ai
